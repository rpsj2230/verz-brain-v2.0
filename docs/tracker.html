§How to use this

Every leaf is a deliverable with a checkbox. A module is complete when every leaf under it is ticked and its invariants pass. Nothing is done because it looks finished.

Ids run four and five levels deep — M0.2.1 is a subtask, M31.1.1.3 a step within one. Put the id in the commit message and the traceability file so progress is a query rather than a meeting.

Ticks are stored in this browser only, so each person tracks their own view. Use Export to produce a JSON snapshot for the traceability file or to share with the team.
