Connectors

Super Admin · company-wide

Connectors are wired three ways — an MCP server where the vendor ships one, a REST adapter where they do not, and a custom adapter for anything in-house. What the table really governs is how little is copied. A connector projects at most twelve fields per entity: identifiers, join keys, enums, timestamps, short labels, and the source's own visibility predicate. Everything else is fetched live at question time and never stored, because the arithmetic leaves no choice: a realistic day would take 15,000 to 60,000 Xero calls against a 5,000 ceiling.

#F47936 Verz orange #231F20 Verz black #14724A healthy #8A6410 attention #A8231B failing #5F4A9B restricted
Both brand values are sampled from the logo file. Two build notes follow from them. First, white text on Verz orange measures 2.77:1 and fails WCAG AA, while Verz black on the same orange measures 5.96:1 — so the orange is used as a fill carrying dark text, and orange text on a white ground darkens to #B75315 to reach 4.96:1. Second, the brand hue sits in the same band as a conventional amber warning, so the brand orange never encodes state: it marks identity, the active rail and the primary action only. Attention is carried by a dark low-chroma ochre that cannot be mistaken for it. Neutrals are warm-biased toward the orange rather than a default grey. Poppins carries the document headings to match the brand; the interface chrome inside each frame is IBM Plex Sans, which holds up at 12px where Poppins does not. Thirteen screens of a build inventory that runs to about forty. The two admin consoles are one build with a scope filter rather than two products, which is why screen 2 looks like screen 1; screens 4 to 11 are shown as content panes because the navigation is already established and repeating it eight times would be noise. Figures are representative of Verz at roughly 3,000 questions a day and are not measurements.
